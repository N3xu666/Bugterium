# 04 Social Media and Content

Social media and content platforms are among the highest-signal sources of
open-source information. They reveal personal details, organizational
structures, technical stacks, and social relationships.

> [!CAUTION]
> Authorized use only. All material is provided for educational purposes and authorized testing.<br>
> See [../../SECURITY.md](../../SECURITY.md) for the full policy.

## Scope

This subcategory covers the systematic collection and analysis of public social media data, including:

- **Platforms:** LinkedIn, X (Twitter), Instagram, Facebook, Reddit, TikTok.
- **Data types:** Profiles, posts, comments, images, video, metadata.
- **Techniques:** Search engine queries, API access, archiving, image geolocation.
